# Contributing to Measure Twice

Thanks for helping improve Measure Twice.

## Reporting bugs and requesting features

Open an issue with one of the forms: [Report a bug](https://github.com/lance6x5/diy-calc-suite/issues/new?template=bug_report.yml) or [Request a feature](https://github.com/lance6x5/diy-calc-suite/issues/new?template=feature_request.yml). The app footer has links that pre-fill the app version and browser for you. Please don't include personal data.

## Triage flow

1. Every new issue gets the `triage` label (plus `bug` or `enhancement`) automatically from its form.
2. The maintainer reviews it, removes `triage`, and relabels or closes it (for example as a duplicate or won't-fix).
3. Work happens on a branch, then a pull request whose description says `Fixes #N` so the issue closes when the PR is merged.
4. User-facing changes are recorded under `Unreleased` in [CHANGELOG.md](CHANGELOG.md) and move into a version section at release time (see "Versioning" in the README).
